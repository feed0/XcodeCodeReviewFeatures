# Code Review on Xcode 16.4
> **_For some reason_** this feature is broken on Xcode 26.x.
> <br>So a turn around is to download Xcode 16.4 from the apple developer betas – it works with MacOS 26.

## Overview
- Changes Navigator
- Pull Request
- File changes

## 1. Changes Navigator (cmd + 2)

> When there is an open PR for the branch you're checked out:

- Hold `command` and hit `2` so the _Soource Control Navigator_ opens,
- Then select the _Changes tab_.
- Finally you can see the PR's:
    - commits
    - files changes – **aggregated instead of grouped by commits**.
<img width="480" height="222" alt="image" src="https://github.com/user-attachments/assets/1e7300bb-9025-44b0-8bf2-45d5aa15ff2e" />
